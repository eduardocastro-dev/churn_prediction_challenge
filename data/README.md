# Dados

Este diretório contém os dados utilizados no projeto de predição de churn.

## Estrutura

### `raw/`

Contém os dados originais, sem alterações ou transformações realizadas durante o desenvolvimento do projeto.

Arquivo utilizado:

`WA_Fn-UseC_-Telco-Customer-Churn.csv`

O dataset contém informações de clientes de uma empresa de telecomunicações e será utilizado para análise exploratória, preparação dos dados e desenvolvimento dos modelos de classificação de churn.

## Fonte

Dataset **Telco Customer Churn**, disponibilizado no Kaggle e sugerido no enunciado do Tech Challenge.

## Observação

Os arquivos armazenados em `raw/` devem ser preservados em seu formato original. Eventuais dados transformados ou processados serão armazenados separadamente para garantir a rastreabilidade e a reprodutibilidade do projeto.
